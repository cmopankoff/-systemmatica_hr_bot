# Доска заказов кухонь — демо-прототип

Автономная страница `index.html`: без сборки, внешних библиотек и сетевых запросов. Открывается двойным щелчком.

**Все данные вымышленные** (заказы «ДЕМО-…», города, каналы, сотрудники). «Предварительный вклад» = сумма заказа − введённые прямые затраты; это не чистая прибыль.

## Что умеет
- 5 колонок: Замер → Дизайн → Согласование → Производство → Монтаж; смена этапа перетаскиванием или списком в карточке (возврат назад требует подтверждения).
- Карточка: номер, канал, город, ответственный, обещанная дата, следующее действие со сроком, сумма, прямые затраты, предварительный вклад.
- Статус срока: просрочен / не успеваем по нормам / впритык / в графике / закрыт. Запас = дней до обещанной даты − сумма норм оставшихся этапов (календарные дни). Нормы в прототипе демонстрационные, меняются кнопкой «Нормы этапов».
- Фильтр по каналу и по риску, поиск, создание/правка/удаление заказа.
- Изменения хранятся в `localStorage` браузера; «Сбросить демо-данные» возвращает исходное состояние.
- Выгрузка CSV (разделитель `;`, UTF-8 с BOM, открывается в Excel) с учётом фильтров.

## Что в прототип не входит
CRM, учёт/1С, календари бригад, уведомления, роли и авторизация. Эти функции требуют интеграций (см. ТЗ).

## Как показать работодателю
1. **GitHub Pages (рекомендуется).** Workflow `.github/workflows/pages.yml` публикует папку при слиянии в `main`. Один раз: *Settings → Pages → Source: GitHub Actions*. Ссылка будет вида `https://<пользователь>.github.io/<репозиторий>/`. Для приватного репозитория Pages доступны не на всех тарифах, тогда сделайте репозиторий публичным: в нём только вымышленные данные.
2. **Запасной вариант.** Приложить `index.html` к письму или выложить в любой статический хостинг; файл работает локально без интернета.
3. В резюме или сопроводительном письме дайте ссылку на демо и на ТЗ, и одной строкой назовите допущения: нормы этапов демонстрационные, данные вымышлены, вклад не равен прибыли.
